# AgriVenture-OS

**An offline-first, trilingual (English, Hindi, and Odia) operating system for agro-food ventures.**

AgriVenture-OS brings farm and food operations together—from biofloc and hydroponic labs to cloud kitchens—with practical finance, compliance, and learning tools.

## What it aims to support

- **Agro-food operations:** workflows for biofloc, hydroponics, and cloud kitchens.
- **Offline-first use:** designed for work in low-connectivity environments, with synchronization when connectivity returns.
- **Trilingual experience:** English (EN), Hindi (HI), and Odia (OR).
- **Break-even finance:** tools to understand costs, pricing, and break-even points.
- **Compliance workflows:** FSSAI-focused record keeping and operational support.
- **Learning resources:** curriculum mapping aligned with IGNOU.

> Project overview: features and capabilities are goals for this project; consult the repository for implementation status.

## GitHub Pages

The project landing page is `index.html` in the repository root. To publish it, open **Settings → Pages** and select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder and save. GitHub will show the published URL in the Pages settings once deployment completes.

## Development

This landing page is a static HTML file and has no build step. Open `index.html` in a browser to preview it locally.
